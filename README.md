# ABECoin-Website
Official website for ABEcoin (Solana token).

## Local preview

You can view the landing page locally without any build tools:

```bash
# From the repo root
python -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000) in your browser and the page will load from `index.html` with styles from `styles.css`. If you prefer not to run a server, you can also open `index.html` directly in your browser, though some browsers may block local fonts when opened from the file system.
